- **CR-01 대화 ID 충돌 제거와 저장 형식 이전**: 대화 신원을 내용 기반 ID로 고정하고, legacy 파일이 남아 있으면 API가 503 `conversation_storage_migration_required`로 fail-closed 한다. 이전 절차 [런북](./ga/CR01_CONVERSATION_STORAGE_MIGRATION_RUNBOOK.md).
- **CR-02 세션 저장 손실·동시 writer 보호**: 세션 저장이 0바이트로 유실되던 경로와 같은 초 ID 충돌을 제거하고, stale write는 409 `stale_session_write`, 내구성 불확실은 503으로 구분한다. 구버전 프로세스와의 동시 실행은 지원하지 않는다(배포 시 구버전 종료 필요). 회귀 테스트가 사용자 홈(`~/.antigravity/sessions`)에 파일을 쓰던 누출도 격리했다.
- **CR-03 실제 sandbox 읽기 경계**: 모델 생성 코드·셸의 읽기 경계가 사용자 트리·`/tmp`·`/var/tmp`·`/var/folders`를 차단한다(fail-closed). macOS에서 허용 목록 구현은 CPython 부팅 SIGABRT로 불가해 계획 §1 절차로 이탈을 기록했다. Linux/Docker backend는 미실측.
- **CR-04 API shell도 동일한 실행·승인 경계**: `POST /api/agent/tools/shell/run`이 현재 권한 모드를 따르고(읽기 전용은 403 `shell_approval_required`), CR-03 읽기 경계와 최소 env를 재사용한다(부모 provider 키·PIN secret 상속 차단). 실행 root는 요청 시작 시 1회 확정되고, sandbox 미적용은 503, timeout은 504다. **`security.sandbox_enabled=false` 배포에서는 이 엔드포인트가 동작하지 않는다.**
- **CR-05 API 키의 브라우저 영속 제거**: provider 키를 `localStorage`에 남기지 않고 입력 중 메모리 → 서버 `.env`(0600, 원자적 교체)만 쓴다. `GET /api/settings`는 부분값 대신 `api_keys_configured`(bool 맵)를 반환하며, 저장 가능 키는 allowlist 8종뿐이다. legacy로 브라우저에만 있던 키는 정화 시 제거되어 재입력이 필요할 수 있다.
- **CR-06 설정 상태가 서버의 진실을 반영**: 설정 화면이 `loading → ready|load-error`, `ready → saving → ready|save-error` 상태를 구분한다. **초기 GET 실패 시 폼이 없어 기본값을 저장할 수 없다.** 서버 소유 값은 GET이 화면을 채우고 서버의 `0` 예산/한도는 기본값으로 대체되지 않는다. 화면의 예산/한도 입력은 브라우저 표시 선호이며 서버 강제 값을 바꾸지 않는다(read-only 병기).
- **CR-07 화면 오류 복구와 잘못된 경로**: 2층 오류 경계(앱 경계는 `PinModal` 바깥, route 경계는 `<main>` 안 `key={location.pathname}`)를 도입했다. 화면에는 식별자(`E-XXXXXXXX`)·분류·시도 횟수만 노출하고 원문은 콘솔로 보낸다. chunk 실패는 재시도 대신 새로고침만 안내하고, 없는 경로는 셸 안 404 안내로 처리한다. **오류 복구는 어떤 storage도 지우지 않는다.**
- **CR-08 설정·명령 팔레트 키보드/접근성**: provider 비밀 입력이 보이는 provider 이름을 `aria-labelledby`로 참조해 **여섯 입력이 낭독으로 구분**된다(이전에는 placeholder가 이름이라 모두 동일). 명령 팔레트가 진짜 modal이 됐다 — `aria-modal="true"`, 초기 focus, Tab/Shift+Tab 순환, Esc로 닫을 때 **열기 전 요소로 focus 복귀**, 열려 있는 동안 배경(사이드바·본문·상단 바·토스트)이 `inert`. 한글 IME 조합을 확정하는 Enter는 명령을 실행하지 않는다. 팔레트 선택 항목 부제목의 색 대비를 3.87:1 → 5.12:1로 올렸다(axe serious 적발). 접근성 게이트 매트릭스에 404 화면을 추가해 **16 → 17 route**(CR-07 blocker 해소).
